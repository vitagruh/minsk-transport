# Транспорт Минска — табло остановок

Веб-приложение (PWA) с живым табло автобусов, троллейбусов и трамваев на выбранных
остановках Минска. Источник данных — неофициальный JSON-интерфейс сайта
[Минсктранса](https://www.minsktrans.by), карта — [OpenFreeMap](https://openfreemap.org)
(данные [OpenStreetMap](https://www.openstreetmap.org)). Ключи API и аккаунты не нужны.

## Возможности

- **Избранное** — карточки остановок с ближайшими прибытиями, автообновление.
- **Поиск** — по локальному справочнику остановок, собранному из маршрутов.
- **Карта** — остановки вокруг, живое табло в нижней панели, транспорт маршрутов
  избранных остановок в реальном времени (обновление каждые 15 секунд).
- **Страница остановки** — живое табло, ближайшие рейсы по расписанию, избранное,
  ссылка для отправки.
- **Настройки** — тема, интервал обновления, фильтры видов транспорта, пересборка
  справочника, очистка данных.
- **PWA** — устанавливается на телефон и компьютер, оболочка приложения доступна
  офлайн (сами данные требуют связи с сервером приложения).

## Требования

- Node.js **20+** (используются встроенные `fetch`, `AbortSignal.timeout`,
  `Headers.getSetCookie`).
- Windows 10/11, macOS или Linux.
- Внешние зависимости не нужны — `npm install` не обязателен.

## Установка

```bash
git clone https://github.com/vitagruh/minsk-transport.git
cd minsk-transport
```

`npm install` не нужен: внешних зависимостей нет.

Репозиторий приватный: при клонировании на другом компьютере или сервере
понадобятся SSH-ключ, personal access token GitHub или deploy key.

## Запуск

```bash
npm start
# приложение: http://127.0.0.1:3000
```

Для разработки с автоматическим перезапуском:

```bash
npm run dev
```

Переменные окружения:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт HTTP-сервера |
| `HOST` | `127.0.0.1` | Интерфейс; `0.0.0.0` — доступ из локальной сети |

Чтобы открыть приложение на телефоне в той же Wi-Fi сети, выполните
`npm run start:lan` — скрипт включит `HOST=0.0.0.0` и покажет адреса компьютера.
В PowerShell то же самое вручную: `$env:HOST='0.0.0.0'; npm start`, в cmd:
`set HOST=0.0.0.0 && npm start`. Установка PWA и геолокация работают в защищённом
контексте, поэтому с телефона удобнее открывать приложение через `localhost`
(проброс портов) или reverse proxy с HTTPS.

## Запуск на Windows

1. Установите Node.js 20+ с [nodejs.org](https://nodejs.org/).
2. Дважды щёлкните `start.cmd` — скрипт проверит версию Node, запустит сервер и
   откроет браузер. Для доступа с телефона запустите `start.cmd lan` из терминала.
3. При первом запуске Windows может спросить доступ в брандмауэре — разрешите
   Node.js для частных сетей (это нужно только в режиме `lan`).
4. Остановка — `Ctrl+C` в окне консоли.

Из терминала работают обычные команды:

```bat
npm start
npm run start:lan
npm run dev
npm run check:api
```

Справочник остановок хранится в `data\stops.json`. Для автозапуска можно добавить
`start.cmd` в Планировщик заданий (при входе в систему) или оформить приложение
службой через [NSSM](https://nssm.cc/): укажите `node.exe` с аргументом `server.js`
и рабочую папку проекта.

## Запуск на Linux

1. Установите Node.js 20+ (из репозитория дистрибутива, через
   [nodesource](https://github.com/nodesource/distributions) или
   [nvm](https://github.com/nvm-sh/nvm)) и `git`.
2. Запустите приложение из папки проекта:

```bash
./start.sh
# приложение: http://127.0.0.1:3000
```

Скрипт проверяет версию Node, берёт `PORT` из окружения (по умолчанию 3000) и
запускает сервер. Если файл потерял права на запуск после распаковки архива:
`chmod +x start.sh`.

Для доступа с телефона в той же сети:

```bash
./start.sh lan
```

Скрипт включит `HOST=0.0.0.0` и покажет IP-адреса компьютера. Откройте показанный
адрес на телефоне и разрешите порт 3000 в брандмауэре (например,
`sudo ufw allow 3000/tcp`). Тот же режим доступен как `npm run start:lan`;
обычные команды `npm start`, `npm run dev` и `npm run check:api` работают так же,
как в Windows.

Для установки PWA и геолокации нужен защищённый контекст: открывайте приложение
через `localhost` (проброс портов) или reverse proxy с HTTPS (Caddy, nginx).

### Автозапуск через systemd

Готовый unit лежит в `deploy/minsk-transport.service`:

```bash
sudo useradd --system --home /opt/minsk-transport --shell /usr/sbin/nologin minsk
sudo git clone https://github.com/vitagruh/minsk-transport.git /opt/minsk-transport
sudo chown -R minsk:minsk /opt/minsk-transport
sudo cp /opt/minsk-transport/deploy/minsk-transport.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now minsk-transport
```

Проверка и логи:

```bash
systemctl status minsk-transport
journalctl -u minsk-transport -f
```

В unit'е поправьте `User`, `Group`, `WorkingDirectory` и `ExecStart`, если Node
установлен в другом месте (`command -v node`). Служба слушает `127.0.0.1` — для
доступа из сети замените `Environment=HOST=127.0.0.1` на `HOST=0.0.0.0` и откройте
порт в брандмауэре.

После обновления (`sudo git -C /opt/minsk-transport pull`) перезапустите службу:

```bash
sudo systemctl restart minsk-transport
```

`start.sh` работает и в macOS; отдельного скрипта для неё не требуется.

## Первый запуск

При первом старте приложение собирает справочник остановок: запрашивает список
маршрутов и остановки каждого маршрута у Минсктранса (около 250 запросов, обычно
1–3 минуты). Прогресс виден в шапке и в настройках. Результат сохраняется в
`data/stops.json` и переиспользуется; справочник обновляется автоматически раз в
12 часов.

Пока справочник собирается, поиск показывает прогресс, а карта и табло уже работают.
Если сборка не удалась, приложение повторит попытку через 5 минут.

## Вежливость к источнику

Сервер работает как кэширующий прокси, чтобы не нагружать сайт Минсктранса:

- прогнозы прибытия — кэш 10 с, расписания — 5 мин, транспорт — 10 с;
- не более 3 одновременных запросов к источнику с паузой 90 мс;
- при ошибке источника отдаются последние успешные данные (с пометкой «могли
  устареть»), затем — расписание;
- сессия и anti-forgery-токен переиспользуются, при протухании обновляются
  автоматически.

Не запускайте несколько экземпляров приложения с интенсивным опросом и не меняйте
интервалы кэша без необходимости. Проект не связан с Минсктрансом.

## Диагностика API

Если данные перестали приходить, проверьте, отвечает ли источник ожидаемым образом:

```bash
npm run check:api
```

Скрипт открывает сессию, получает токен и последовательно проверяет `RouteList`,
`Route`, `Scoreboard`, `SchedulesByStop`, `NearestStops` и `Vehicles`. Ненулевой код
возврата означает, что API изменился или сайт ограничил доступ.

## Структура

```
server.js              HTTP-сервер и API приложения
start.cmd              запуск на Windows (двойной клик; start.cmd lan — сеть)
start.sh               запуск на Linux и macOS (./start.sh lan — сеть)
deploy/                unit-файл systemd
lib/minsktrans.js      клиент неофициального API (сессия, токен, лимиты)
lib/normalize.js       нормализация ответов, расписание, время Минска
lib/directory.js       справочник остановок из маршрутов
lib/cache.js           TTL-кэш и ограничитель запросов
public/                PWA: интерфейс, стили, service worker, иконки
scripts/start-lan.mjs  запуск с доступом из локальной сети
scripts/check-api.mjs  диагностика источника
data/stops.json        справочник остановок (создаётся автоматически)
```

Внутренние эндпоинты: `/api/health`, `/api/search`, `/api/near`, `/api/stop/:id`,
`/api/stop/:id/schedule`, `/api/vehicles/:tt/:route`, `/api/vehicles?stops=:ids`,
`POST /api/directory/rebuild`.

## Установка как приложение

Откройте сайт в Chrome/Edge и выберите «Установить приложение» (или «Добавить на
главный экран» на Android). Интерфейс кэшируется service worker'ом; избранное и
настройки хранятся локально в браузере. Тайлы карты не кэшируются — для карты нужна
сеть. Для обновления service worker после изменений фронтенда увеличьте версию
`CACHE` в `public/sw.js`.

## Ограничения

- Источник неофициальный: формат и доступность могут измениться без предупреждения.
- Прогнозы прибытия — оценка Минсктранса; при сбое источника показывается расписание.
- Метро отображается только как фильтр; табло метро в источнике для остановок нет.
- Карта использует векторные стили OpenFreeMap (Positron для светлой темы, Dark для
  тёмной) и MapLibre GL JS. Ключ не требуется, атрибуция OpenFreeMap/OpenMapTiles/OSM
  отображается на карте. Стили и тайлы не кэшируются офлайн.
- Приложение не собирает аналитику и не отправляет данные третьим лицам, кроме
  запросов к сайту Минсктранса с сервера приложения и загрузки карты/MapLibre из
  OpenFreeMap/unpkg.
